Decisions

Why I Chose This Stack

I chose React for the frontend because it makes it easy to build reusable UI components and manage application state. I chose Node.js with Express.js for the backend because it is lightweight and integrates well with React. MongoDB was selected because it provides flexible document-based storage and works efficiently with Mongoose.

Additional Decision

The assignment did not specify how registrations should be tracked. I decided to store a registration count within each event document and update it whenever a student registers. This allows the admin dashboard to display fill percentages efficiently.

What I Would Improve With More Time

If given more time, I would implement proper authentication using JWT tokens and encrypted passwords instead of hardcoded credentials. I would also improve the UI design and add validation for all user inputs.
